# Icons

The drawings under this directory are **vendored by hand** at a pinned tag and are not build output. What *is* generated from them is everything else: the constants, both `Icon` implementations, the manifest, and this file.

Every drawing is checksummed. `cargo xtask check` verifies each one against the `SHA256SUMS` recorded when it was fetched, and fails on a file that changed, a file that is missing, and a file the list does not mention.

`NOCTUA.md §9.5` used to keep the set to what the interfaces used, because *"an unused icon is payload and review surface"*. That is still true and it is now enforced by measurement: an icon nothing names reaches no binary and no bundle, and `cargo xtask check` proves it on a linked release binary and on a real bundler's output.

### What this system reaches for, and why

Every other drawing from this source is swept in under its own name and is documented by that name alone.

| Icon | File | For |
|---|---|---|
| `alert` | `circle-alert.svg` | Marks a message about something that has already gone wrong, such as a refused payment. Paired with the danger tone, never standing in for it. |
| `arrow-down` | `arrow-down.svg` | The same, the other way. Two arrows rather than one rotated by the stylesheet: a transform is a thing a preset or a reduced-motion path can reach, and the direction of a sort is not something to leave to CSS. |
| `arrow-up` | `arrow-up.svg` | A column sorted from the beginning of the alphabet, or the smallest number. Paired with `aria-sort="ascending"`, which is what a screen reader reads; the arrow is the half a reader can see. |
| `atom` | `atom.svg` | Moves an example to the React implementation. |
| `calendar` | `calendar.svg` | Opens a month: a `DatePicker`'s own box carries one, and so does the control on a `DateInput` that opens its suggestions. A calendar, because that is what opens. Both controls are icon-only and are named by a prop. |
| `check` | `check.svg` | Confirms an action, and marks the option in force. |
| `chevron-down` | `chevron-down.svg` | The disclosure marker on a `<details>` summary. |
| `chevron-left` | `chevron-left.svg` | The previous slide, on a `Carousel`. A chevron rather than an arrow: an arrow in this system marks the direction a column is SORTED, and one drawing meaning two things is how a reader learns to distrust both. |
| `chevron-right` | `chevron-right.svg` | The next slide, on the same terms. The pair is mirrored by the stylesheet in a right-to-left locale, which is the one place a transform is the right answer — *previous* means the other way there. |
| `chevrons-up-down` | `chevrons-up-down.svg` | A column that can be sorted and is not — the affordance. Without it a sortable heading looks exactly like a fixed one until somebody presses it, which is a feature nobody finds. |
| `clock` | `clock.svg` | Marks a time, such as when a row of a schedule names one. A clock face with two hands, which is the drawing every reader already reads as a time. No component draws it on its own. |
| `close` | `x.svg` | Dismisses the drawer or a floating surface. |
| `columns-2` | `columns-2.svg` | Opens the list of a table's columns, where a reader chooses which are shown. It was `columns` until the set was vendored at `1.33.0`, where upstream numbers the panel counts; the name was never this system's choice, so it follows upstream. |
| `copy` | `copy.svg` | Copies a code block to the clipboard. |
| `dna` | `dna.svg` | Moves an example back to the Dioxus implementation. |
| `download` | `download.svg` | Opens the menu that takes a table away as a file. |
| `external-link` | `external-link.svg` | Marks a link that leaves the site. Replaces a bare `↗` character, which is text pretending to be an icon. |
| `eye` | `eye.svg` | Shows a password, on a `Input { kind = "password" }`. A reader who cannot see what they typed cannot correct it, and the alternative they reach for is a shorter password. |
| `eye-off` | `eye-off.svg` | The other half of that toggle, on a password. Both are rendered and the state picks one, because swapping a drawing from script means shipping a drawing to the script. |
| `flask-conical` | `flask-conical.svg` | Puts an example frame under a glass test: colour and edges behind it, blank space and a scrollbar, and the material on everything inside. A flask, because what the control is is a test rig — `layers` and `image` were both here first, and both described the backdrop rather than the thing being done with it. |
| `info` | `info.svg` | Opens the note explaining what a heading or a value means. |
| `languages` | `languages.svg` | Opens the language menu. Not a flag: a flag names a country and this names a language, and the two disagree for most languages anybody speaks. |
| `menu` | `menu.svg` | Opens the navigation drawer. |
| `minus` | `minus.svg` | Subtracts one step, on a `NumberInput`. A minus rather than a downward chevron: the control changes a quantity, and a chevron says *move* about a thing that is not moving. |
| `monitor` | `monitor.svg` | The appearance mode the operating system asked for. |
| `moon` | `moon.svg` | The dark appearance mode. |
| `palette` | `palette.svg` | Opens the theme menu. A palette rather than a gear: the menu is the appearance of the page — its mode, its accent, its corners — and a gear says "settings" about a product that has no other kind. |
| `pause` | `pause.svg` | Stops a `Carousel` rotating. WCAG 2.2.2 requires a way to stop anything that moves for more than five seconds, and this is it — the component refuses to start rotating without it. |
| `pipette` | `pipette.svg` | Takes a colour off the screen, on a `ColorPicker` with `eyedropper`. Drawn rather than absent where the browser has no `EyeDropper`: the button is what the script removes, and an icon nothing renders is not payload. |
| `play` | `play.svg` | The other half of that toggle. Both are rendered and the state picks one, because swapping a drawing from script means shipping a drawing to the script. |
| `plus` | `plus.svg` | Commits the colour under the cursor to a `ColorPicker { multiple }`'s list. A plus rather than a check: a check says *this one is chosen*, which is what the option rows already say, and this says *and one more*. |
| `rotate-ccw` | `rotate-ccw.svg` | Puts an example frame back the way it was found: its width, its appearance and its glass test all at once. An arrow that comes back round to where it started, which is the one gesture in this set that means *undo my changes* rather than *go back a step* — `chevron-left` is already the carousel's previous slide, and one drawing meaning two things is how a reader learns to distrust both. |
| `search` | `search.svg` | Marks the search field. |
| `settings` | `settings.svg` | Settings that are not the theme. `Disclosure` documents itself with it. |
| `star` | `star.svg` | One step of a `Rating`. The outline is the empty step and the stylesheet fills the same geometry for the full one, so a rating is one drawing rather than two that could drift apart. |
| `sun` | `sun.svg` | The light appearance mode. |
| `text-wrap` | `text-wrap.svg` | Toggles line wrapping in a code block. It was `wrap-text` until the set was vendored at `1.33.0`; the name was never this system's choice, so it follows upstream. |
| `upload` | `upload.svg` | Marks a `FileInput`'s drop area. An arrow into a tray, which is what the gesture is; a paperclip would say *attachment*, which is what the result is called and not what the control does. |
| `user` | `user.svg` | A person, where there is no picture of them. `Avatar`'s last fallback, after the initials. |
| `warning` | `triangle-alert.svg` | Marks a message about something that is about to go wrong. The triangle is the shape, and the sentence beside it is what says what is wrong. |
