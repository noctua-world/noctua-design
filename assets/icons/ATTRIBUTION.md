# Icons

The drawings under this directory are **vendored by hand** at a pinned tag and are not build output. What *is* generated from them is everything else: the enum, both `Icon` implementations, the manifest, and this file.

Only icons the interface actually uses are here. `NOCTUA.md §9.5`: *"an unused icon is payload and review surface"* — and the build enforces it in both directions, so a drawing nothing declares fails `cargo xtask check`.
