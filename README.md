# noctua-design

The Noctua design system: tokens and components, as **two packages that behave
identically** — a Dioxus crate and a React package — plus a documentation site.

> **Status: the repository base.** The machine that builds components is here.
> No component is, yet — that is Stage 6, and building one before the machine
> means rebuilding it. See [`NOCTUA-PLAN.md`](../../NOCTUA-PLAN.md).

---

## Two rules, and they matter more than they look

### 1. Clone this **only** inside `noctua-workspace/repos/`

```sh
cd /home/noctua/main/prjs/noctua-workspace/repos
git clone <this repository>
```

Anywhere else and this repository cannot reach the shared documents or its
sibling repositories — including `noctua-colors`, whose output it vendors.

### 2. Start your agents **only** from the workspace root

```sh
cd /home/noctua/main/prjs/noctua-workspace
claude                     # or whichever agent you use
```

**Not** from inside this directory. An agent started here cannot see
`noctua-colors`, cannot read the master technical reference, and will guess
instead of looking. It detects this itself and prints a loud warning — if you
see one, close it and reopen it at the workspace root.

## Quick start

Requires only a Rust toolchain. Nothing to install first: the `cargo xtask`
alias ships in `.cargo/config.toml`, and the WebAssembly target is declared in
`rust-toolchain.toml`.

```sh
cargo xtask check
```

That validates `spec/`, runs every source gate, verifies the generated output
matches, and runs formatting, lints and tests. It is the same command CI runs.

```sh
cargo xtask build     # compile spec/ into tokens, icons and dist/
cargo xtask dev       # ...and serve the docs site with live reload
```

**Node is optional.** It is needed only for the React package and the
conformance runner. The Rust half of this repository builds and tests without
it, and `cargo xtask check` proves that rather than assuming it.

## What is here

| Path | What it is |
|---|---|
| `spec/tokens.toml` | Every non-colour token — spacing, radii, typography, motion, layers, breakpoints. **The only file you edit to change them** |
| `spec/i18n/` | Every UI message, in English and Brazilian Portuguese |
| `spec/components/` | The component contracts and their shared behavioural cases |
| `crates/noctua-design/` | The Dioxus package |
| `packages/react/` | The React package |
| `crates/noctua-design-tokens/`, `packages/tokens/` | **Generated** from `spec/tokens.toml`, and committed |
| `packages/tokens/vendor/` | The colour tokens, **generated by `noctua-colors`**. Never edited here |
| `assets/fonts/` | The subset fonts, their licences, and a reproducible attribution |
| `dist/` | **Generated, committed**: `noctua-design.css` and its manifests |

Generated directories are committed so every consumer works with no build step.
`cargo xtask check` fails if one drifts from `spec/`.
