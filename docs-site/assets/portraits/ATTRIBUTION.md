# The portraits

Ten flat vector portraits — eight people and two of them again in a paper hat,
for the seasonal example — generated by the script recorded below, used by the
`Lineage` examples so the documentation shows what a scene of **people** looks
like rather than a scene of initials.

**They are nobody.** No photograph of any person appears in this repository, and
none of these is a likeness of one — they are the same kind of placeholder a
consumer replaces with their own `image=` or `Avatar { src }`.

**Their colours are content, not interface.** The rule that this repository
defines no colour is about what the interface is painted with; a portrait is
what a consumer's photograph would be, and a photograph does not come from the
palette. Nothing here is referenced by any stylesheet.

Regenerate them by re-running the script in the change that added this file, or
replace them wholesale: the examples reference them only by name.
